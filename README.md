# 🛍️ E-Commerce Portal UI (Digikala Redesign)

A modern, responsive, RTL-first frontend web implementation inspired by the Digikala marketplace. Built using clean HTML5 semantics, modular CSS Grid, and custom Flexbox components.

![Lighthouse Score](https://img.shields.io/badge/Lighthouse-Performance%20Optimized-success)
![RTL Ready](https://img.shields.io/badge/Layout-RTL%20First-blue)
![Zero Dependencies](https://img.shields.io/badge/Dependencies-0-orange)

## 🌟 Highlights
- **RTL-First Architecture:** Native Right-to-Left typographic hierarchy tailored for Persian/Arabic typography (`vazirmatn` / `iranyekan`).
- **Interactive Multi-Level Mega Menu:** Hover-activated category navigation with sub-tier grid distribution.
- **Fluid & Accessible Controls:** Fully responsive layouts across 4K displays down to standard 360px mobile viewports.
- **Performant CSS Animations:** Hardware-accelerated transitions and optimized scroll containers with zero layout shift (CLS).

## 🗂️ Component Architecture
- **Header:** Sticky blurred glassmorphism navbar with quick search and user action triggers.
- **Stories Carousel:** Mobile-touch enabled horizontal story container.
- **Flash Sales (Amazing Offers):** High-converting promotional product carousel with dynamic discount tags.
- **Categorical Breakdown:** Auto-fit CSS Grid adapting seamlessly to viewport changes.

## 🛠️ Tech Stack
- **HTML5:** Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Custom Properties (CSS variables), CSS Grid, Flexbox, Media Queries.
- **Font Face:** High-clarity webfont integration.
